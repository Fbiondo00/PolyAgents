# ETHGlobal Cannes 2026 — Project Submission

## Short Description (max 100 chars)

AI autonomous trading vault for Polymarket BTC 5-min markets across Arc, Hedera, and ENS.

## Description (min 280 chars)

PolyAgents is an AI-powered autonomous trading vault that scalps Polymarket BTC "Up or Down" 5-minute binary markets using a passive market-making strategy. The agent places $0.01 limit bids on both sides and flips fills at $0.02, capturing a 100% spread on each trade. The system operates as a deterministic state machine — cycling through market discovery, quoting, inventory management, expiry guarding, and rollover — with an optional AI microstructure analysis layer that estimates fill probability, optimal tranche sizing, and expiry risk using GPT-4o-mini. Users create vaults through a 5-step wizard, fund them with USDC on Arc, and toggle between advisory mode (human confirms each cycle) and auto mode (agent acts autonomously). Every agent decision is immutably logged to Hedera Consensus Service (HCS) for a fully auditable trail, with 0.001 HBAR micropayments fired before each LLM call to demonstrate autonomous agent-to-agent payments. Vault strategy parameters are cryptographically committed as keccak256 hashes stored on ENS text records under vault subnames, allowing public verification that the agent follows its declared policy without revealing the actual strategy. HTS non-transferable tokens gate access to auto-trading mode. The frontend is built as a complete Next.js 16 dashboard with real-time PnL sparklines, order book visualization, audit timeline with CSV export, and an agent control panel showing live AI reasoning and cycle logs. The project targets three sponsor tracks: Arc for USDC-native prediction market settlement, Hedera for No Solidity (HTS+HCS only) and AI Agentic Payments, and ENS for the creative cryptographic commitment pattern on text records.

## How It's Made (min 280 chars)

The frontend is a Next.js 16.2 App Router application with React 19, TypeScript strict mode, Tailwind CSS 4 with a custom dark theme, shadcn/ui components (Radix primitives with CVA variants), Recharts for PnL sparklines and audit bar charts, and Zod for runtime validation. All routing uses the App Router with client components — there are no Server Components or API routes in the current prototype. State lives entirely in localStorage with a typed Vault data model containing nested strategy parameters, funding balances, inventory ledgers, audit event arrays, and sparkline data points. The trading strategy state machine (IDLE → DISCOVERING_MARKET → READY → QUOTING → HOLDING_INVENTORY → EXPIRY_GUARD → ROLLING_OVER → RECONCILING) is simulated client-side via a CycleButton component and auto-mode interval. For Arc integration, a planned PolyAgentsMarket Solidity contract handles binary prediction market creation, USDC betting, resolution, and claim flows on the Arc EVM L1 where USDC is the gas token. Hedera integration uses the @hashgraph/sdk and @hashgraph/hedera-agent-kit — HTS for non-transferable token gating with custom fee schedules, HCS for per-vault audit topics with Mirror Node queries, scheduled transactions for future-dated rebalancing, and HCS-14 for on-chain agent identity (UAID). Each autonomous cycle pays 0.001 HBAR before invoking the LLM, creating a verifiable agentic payment trail. ENS uses viem on Sepolia to write keccak256(strategyParams) as a text record on vault subnames, plus live agent stats (flips, PnL, inventory, mode) as queryable text records. Authentication is handled through Privy for multi-chain wallet creation with email, social login, or wallet connect — providing instant testnet wallets auto-funded with Arc USDC, Hedera HBAR, and Polygon MATIC. The planned backend adds Supabase Postgres for persistence, @polymarket/clob-client for real CLOB trading, and WebSocket subscriptions for live market data.
