## Description (min 280 chars)

PolyAgents is an AI-powered autonomous trading vault that scalps Polymarket BTC "Up or Down" 5-minute binary markets using a passive market-making strategy: place $0.01 limit bids on both sides, flip fills at $0.02, capture 100% spread. Each trading cycle runs a 13-step server-side pipeline orchestrated by Next.js Server Actions — from market discovery through AI analysis, order placement, fill checking, inventory management, PnL reconciliation, and ENS stat updates. The AI layer runs on every cycle using Gemini 2.0 Flash Lite via Vercel AI Gateway, estimating fill probability, optimal tranche sizing, and expiry risk to inform each trading decision. Before each LLM call, the agent pays HBAR proportional to actual token usage (calculated from input/output token counts at a $0.25/HBAR reference rate), creating a verifiable autonomous payment trail — every transaction logged to Hedera Consensus Service for a fully auditable decision history. Vault strategy parameters are cryptographically committed as keccak256 hashes stored on ENS text records under vault subnames, allowing anyone to verify the agent follows its declared policy without revealing the strategy itself. Live agent stats (flips, PnL, mode, engine state) are queryable as ENS text records, and agent identity is registered via ENSIP-25 linking the ENS name to the vault's HCS-14 on-chain identity. USDC settlement runs through a deployed PolyAgentsMarket Solidity contract on Arc Testnet, with Circle CCTP bridging funds between Arc and Polygon as needed for Polymarket CLOB execution. Authentication is handled by Privy with instant testnet wallet creation and auto-funding. The project targets $15,500 across six prize tracks: Arc Best Prediction Markets ($3,000), Arc Best Chain Abstracted USDC Apps ($3,000), Arc Best Agentic Economy with Nanopayments ($6,000), Hedera No Solidity ($1,000), Hedera AI & Agentic Payments ($3,000), and ENS Most Creative Use ($2,500).

## How It's Made (min 280 chars)

The application is a Next.js 16.2 App Router project with React 19, TypeScript strict mode, Tailwind CSS 4 with a custom dark theme, shadcn/ui components, Recharts for PnL sparklines and audit bar charts, and Zod for runtime validation. The backend layer consists of 22 Server Action modules and 2 Vercel cron API routes (reconciliation and profit repatriation) — all chain interactions run server-side, not in the browser. Engine state is persisted to a server-side JSON store, with vault metadata synced to localStorage for the frontend. The trading engine implements an 11-state deterministic state machine (IDLE → DISCOVERING_MARKET → SYNCING_MARKET → READY → QUOTING → HOLDING_INVENTORY → EXPIRY_GUARD → ROLLING_OVER → RECONCILING → PAUSED → ERROR) driving a 13-step pipeline per cycle: discover market, AI analysis, pay oracle, handle expiry, ensure Polygon liquidity, place bets, check fills, sell coverage, mirror to Arc, reconcile, calculate PnL, repatriate profits, and update ENS. AI analysis uses Gemini 2.0 Flash Lite via Vercel AI Gateway with per-call cost tracking. For Arc, a deployed PolyAgentsMarket Solidity contract (Arc Testnet, Chain ID 5042002) handles binary prediction market creation, USDC betting, resolution, and claim flows — USDC is the native gas token. Circle CCTP (via @circle-fin/app-kit) bridges USDC between Arc and Polygon for Polymarket CLOB execution. Polymarket integration uses @polymarket/clob-client with a dual-mode adapter (live CLOB trading + read-only fallback). Hedera integration uses pure @hashgraph/sdk TypeScript — HTS for fungible vault tokens with custom fee schedules and non-transferable operator tokens, HCS for per-vault audit topics with Mirror Node REST API queries, scheduled transactions for future-dated operations, and HCS-14 for on-chain agent identity (UAID). Each cycle pays HBAR proportional to actual LLM token usage before inference. ENS uses viem on Sepolia for subname creation and text record R/W — policy commitment hashes, live agent stats, ENSIP-25 agent identity registration linking to the HCS-14 UAID, and a fleet registry for multi-vault coordination. Authentication is handled by Privy (@privy-io/react-auth) with email and social login, providing instant testnet wallets auto-funded with Arc USDC, Hedera HBAR, and Polygon MATIC.
